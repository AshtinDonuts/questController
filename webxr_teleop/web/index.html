Controls

Grip (hold)Move the matching arm (left grip in dual mode). Release to re-position your hand ("clutch").
TriggerClose the matching gripper while held.
Right ANext step: move home → start recording → save episode.
Right BDiscard the episode being recorded.
Left YSlowly move all active arms to the home pose.
Left XAlign the frame: release both grips (dual mode); hold the right controller naturally: red X right, green Y up, blue +Z backward (−Z forward along the arm's reach), then press. World axes: X right, Y forward, Z up.
Right stick clickShow / hide the alignment aids: each active gripper’s orientation (translucent axes at its controller) and the robot base axes (above the left controller).

Terminal: Ctrl+C stops and finalizes the session MP4. A/B manage episode markers; the whole session is recorded.
